# Banco de preguntas · Policía Nacional · Tema 3

Banco inicial de 50 preguntas propias, dos por cada uno de los 25 bloques semánticos de la fuente maestra.

- Tres opciones por pregunta.
- Respuestas A/B/C equilibradas.
- Sin preguntas oficiales no verificadas.
- Estado: revisado editorial, no publicado.
- Versión normativa: 2026-07-16.

`preguntas.jsonl` es la fuente canónica. Cada línea contiene una pregunta independiente y validable.
