# Banco de preguntas · Policía Nacional · Tema 3

Banco maestro v0.3.0 generado desde 470 hechos atómicos del Atestado.

- 738 preguntas propias.
- 100 % de hechos atómicos con al menos una pregunta.
- Los hechos de riesgo 5 tienen una segunda pregunta inversa de artículo.
- Tres opciones por pregunta.
- Ninguna pregunta se presenta como oficial.
- Estado: revisado contra fuentes oficiales; no publicado.

`preguntas.jsonl` es la fuente canónica del banco. `cobertura.json` permite demostrar qué contenido está preguntado.
